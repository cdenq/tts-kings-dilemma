# King's Dilemma (Remaster)

Scripts and custom art for my remaster of the [*The King's Dilemma*](https://steamcommunity.com/sharedfiles/filedetails/?id=3832723951) mod for Tabletop Simulator on Steam.

Not maintained as a walkthrough or working repo; more a repo dump for versioning across machines, and if anyone else finds it useful for their own games (e.g., the custom assets I've made), go ahead!
